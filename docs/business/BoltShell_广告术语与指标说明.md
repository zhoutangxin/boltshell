# BoltShell 广告术语与指标说明

> 用途：谈赞助 / 做官网广告 / 给甲方报数据时，统一口径。  
> 范围：SSH 客户端赞助位 + 官网网页广告。  
> 相关文档：[赞助位配置说明](BoltShell_赞助位配置说明.md) · [商业化与开源策略](BoltShell_商业化与开源策略.md) · [文档索引](../README.md)

---

## 一、一句话总览

| 术语 | 中文 | 一句话 |
|------|------|--------|
| **PV** | 页面浏览量 | 页面被打开了多少次（可重复） |
| **UV** | 独立访客 | 多少个「不同的人」来过（去重） |
| **DAU** | 日活跃用户 | 当天至少用过一次的用户数 |
| **MAU** | 月活跃用户 | 当月至少用过一次的用户数 |
| **slot** | 广告位 / 赞助位 | 界面上一个固定的投放位置 |
| **曝光（Impression）** | 展示次数 | 广告被真正显示出来的次数 |
| **点击（Click）** | 点击次数 | 用户点了广告跳转的次数 |
| **CTR** | 点击率 | 点击 ÷ 曝光 |
| **CPM / CPC / CPT** | 计价方式 | 按千次曝光 / 按点击 / 按时间包断 |

## 二、流量与用户指标

### 2.1 PV（Page View）— 页面浏览量

- **含义**：某个页面被加载 / 浏览的总次数。同一人刷 10 次 = **10 PV**。
- **官网场景**：首页打开 1 次算 1 PV；刷新再算 1 次。
- **客户端注意**：桌面 App **没有网页 PV**。不要把「启动次数」硬叫 PV；应叫 **启动次数** 或 **会话次数**。
- **甲方常问**：官网日 PV / 月 PV。有就报；没有就说「主投放在客户端，官网仅辅助」。

### 2.2 UV（Unique Visitor）— 独立访客

- **含义**：统计周期内，去重后的访客数。同一人一天来 10 次，日 UV 仍算 **1**。
- **常见去重**：Cookie、设备 ID、登录账号（口径要写清楚）。
- **官网**：日 UV、月 UV。
- **客户端近似**：更接近「日活设备数 / 日活用户」，习惯上仍用 **DAU**，少说 UV。
- **和 PV 关系**：PV ≥ UV；PV/UV 越大，人均打开次数越多。

### 2.3 DAU（Daily Active Users）— 日活跃用户

- **含义**：自然日内，至少发生过一次「有效使用」的用户数。
- **BoltShell 建议口径**（客户端）：
  - 当天至少 **启动客户端 1 次**；或
  - 当天至少 **成功建立 1 次 SSH 连接**（更严、更贴近运维场景，谈赞助时可二选一写明）。
- **用途**：看粘性、算日曝光上限粗估。
- **注意**：Pro 用户不看赞助位，报「可售触达」时应用 **免费 DAU**，不要用全体 DAU。

### 2.4 MAU（Monthly Active Users）— 月活跃用户

- **含义**：自然月内至少活跃过 1 天的去重用户数。
- **和 DAU 关系**：
  - **DAU/MAU**：粘性（越高越好，常见产品约 10%～40%）。
  - 同一用户一个月用 20 天，MAU 只算 1，DAU 会累加多天。
- **谈赞助首选**：甲方最爱问 **MAU**（盘子多大）+ **免费占比**。
- **粗算曝光**：`免费 MAU × 人均每天看到广告次数 × 当月天数`（文档商业化粗算曾用「每人每天约 2 次」）。

### 2.5 下载量 / 安装量（Downloads / Installs）

- **含义**：安装包被下载或安装的次数（未必等于活跃用户）。
- **用途**：产品早期还没有稳定 DAU/MAU 时，可作「盘子」参考。
- **注意**：下载量通常 **大于** MAU（下了不用、换设备重装等）。

### 2.6 留存（Retention）— 选讲

| 术语 | 含义 |
|------|------|
| 次日留存 | 今天新增用户里，明天还来的比例 |
| 7 日 / 30 日留存 | 一周 / 一月后还回来的比例 |

广告侧较少直接谈价，但高留存说明曝光可持续，可作加分项。

## 三、广告位与展示指标

### 3.1 slot（广告位 / 赞助位）

- **含义**：产品里一个 **固定、可配置** 的投放位置；每个 slot 有唯一 ID。
- **BoltShell 客户端内置 slotId**：

| slotId | 场景 | 类型 |
|--------|------|------|
| `quick_connect_bottom` | 未连接 · 快速连接页底部 | banner |
| `sidebar_1` | 已连接 · 系统信息侧栏底 | compact（主售） |
| `sidebar_2` | 已连接 · 侧栏底第二条 | compact（默认自营 Pro） |

- **和「广告」的区别**：我们对外更推荐叫 **赞助位**（精选合作、按月包断），而不是通用广告联盟位。
- **配置**：远程 `sponsors.json` 的 `slots` 字典；详见赞助位配置说明。

### 3.2 曝光 / 展示（Impression）

- **含义**：广告 **被用户看见（渲染出来）** 的次数。同一用户一天看 5 次 = 5 次曝光。
- **客户端**：某 slot 出现在界面上即计 1 次（需埋点；未埋点前可用估算）。
- **官网**：某广告模块进入可视区域，或页面加载时展示（口径需统一）。
- **不要混淆**：
  - 配置接口拉取 `sponsors.json` 的次数 ≠ 曝光（那是技术请求，不是给人看的）。
  - 客户端启动次数 ≠ 某 slot 曝光（未连接才出快速连接底；已连接才出侧栏）。

### 3.3 点击（Click）与 CTR（Click-Through Rate）

| 术语 | 含义 | 公式 |
|------|------|------|
| **点击** | 用户点击赞助条并跳转外链 | 次数累加 |
| **CTR** | 点击率 | `点击次数 ÷ 曝光次数 × 100%` |

- 开发者工具类 CTR 通常不高，谈赞助时 **曝光 + 人群精准** 比 CTR 更重要。
- 甲方可用 UTM 参数自己统计落地页转化（注册、下单）。

### 3.4 关闭 / 拒登（Dismiss）

- **BoltShell 行为**：免费用户点 × → 该 slot 隐藏 **默认 7 天**（`dismissDays`）。
- **关闭率**：`关闭次数 ÷ 曝光次数`。过高说明文案或样式打扰，影响续约。

### 3.5 可售触达（Sellable Reach）

- **含义**：真正能看到赞助位的用户规模。
- **BoltShell 口径**：约等于 **免费活跃用户**（Pro / 持有 `license.dat` 的不展示）。
- 报给甲方时写清：**「免费 MAU，不含 Pro」**。

## 四、计价与合作术语

### 4.1 CPM（Cost Per Mille）— 按千次曝光

- **含义**：每 1000 次曝光收多少钱。
- **例子**：CPM ¥5 → 10 万次曝光 ≈ ¥500。
- **文档结论**：SSH / 开发者工具 CPM 往往偏低，**不宜只靠 CPM 养活产品**。

### 4.2 CPC（Cost Per Click）— 按点击

- **含义**：用户每点一次付一次费。
- **适用**：效果广告；早期无稳定点击数据时难谈。

### 4.3 CPT / 包月赞助（Cost Per Time）— 按时间

- **含义**：按天 / 周 / **月** 买断某个 slot，不论实际曝光多少。
- **BoltShell 推荐**：`sidebar_1` 等按月赞助（文档参考约 **¥500–2000/月**）。
- **优点**：报价简单、收入稳定、界面不像「广告软件」。

### 4.4 其他常见词

| 术语 | 含义 |
|------|------|
| **素材 / Creative** | 标题、描述、角标、图片、跳转链接 |
| **落地页** | 点击后打开的页面 |
| **UTM** | 链接上的追踪参数，方便甲方在自己后台归因 |
| **独家** | 某周期内该位只给一家赞助商 |
| **排期** | 哪段时间上哪家素材 |
| **媒体包 / Media Kit** | 给甲方的一页纸：用户规模、位图、报价、人群 |

## 五、BoltShell 报数口径（建议统一）

对外说话时，建议固定下面几套数，避免和甲方各说各话：

### 5.1 客户端（主投放）

| 给甲方的字段 | 建议口径 |
|--------------|----------|
| 用户规模 | 免费 **MAU**（注明不含 Pro） |
| 粘性（可选） | **DAU**、或 DAU/MAU |
| 盘子参考 | 累计下载 / GitHub·Gitee Star |
| 曝光 | 分 **slot** 的日/月曝光（有埋点报实数；无则写「估算方法」） |
| 互动 | 点击、CTR、关闭率（有则报） |
| 人群 | 国内运维 / 后端 / 多机管理用户 |
| 合作方式 | **CPT 包月**，非通用广告 SDK |

### 5.2 官网（辅助）

| 字段 | 建议口径 |
|------|----------|
| 流量 | 日/月 **PV**、**UV** |
| 广告位 | 若有 Footer / Banner，单独列出 slot 名称与尺寸 |
| 说明 | v1 规划里官网可仅 Footer 文字链；客户端才是主赞助位 |

### 5.3 禁止混用的说法

| 错误说法 | 正确说法 |
|----------|----------|
| 「我们 PV 有 XX」（指客户端） | 「日启动 / 日曝光 / DAU」 |
| 「sponsors.json 调用量 = 广告曝光」 | 「配置拉取 ≠ 曝光」 |
| 「全体 MAU 都能看到广告」 | 「仅免费用户；Pro 去广告」 |
| 「三个广告同时出现」 | 「未连接 1 条；已连接侧栏最多 2 条，互斥」 |

## 六、速查对照（网页 vs 客户端）

| 概念 | 官网网页广告 | SSH 客户端赞助位 |
|------|--------------|------------------|
| 人来了多少 | UV | DAU / MAU（设备或账号去重） |
| 看了多少次页 | PV | 启动次数 / 连接会话（勿叫 PV） |
| 广告看了几次 | 曝光 Impression | 某 **slot** 展示次数 |
| 广告在哪 | 页面上的 Banner/Footer | `quick_connect_bottom` / `sidebar_*` |
| 常用计价 | CPM / CPC / CPT | **更推荐 CPT 包月赞助** |

## 七、记忆口诀

1. **PV 看次数，UV 看人数**  
2. **DAU 看一天，MAU 看一月**  
3. **slot 是坑位，曝光是看见，点击是跳转**  
4. **BoltShell 卖的是赞助位包月，不是网页 PV 堆出来的联盟广告**
