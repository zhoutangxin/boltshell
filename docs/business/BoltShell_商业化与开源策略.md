## 一、总体结论（先看这个）

| 维度 | 建议 |
|------|------|
| **主收入模式** | Freemium + Pro 买断 + Team 订阅（不要只靠广告） |
| **广告** | 可以做，放在非操作区；作为免费版补贴 + Pro 转化钩子 |
| **云厂商 CPS** | **优先级高于展示型赞助位**（阿里云最高 35% / 腾讯云 20%–35%）；量级可能超过赞助位，口碑代价接近零 |
| **开源** | Open Core：Community 开源获客，Pro/Team 闭源赚钱 |
| **许可证** | Community 用 Apache 2.0（仓库已有），商标 BoltShell 单独保护 |

**一句话策略：**

> 用「免费、轻量、比 FinalShell 干净」抢个人用户；用「无限连接 + 效率工具 + 去广告」卖 Pro；用「团队同步 + 审计」卖公司；Community 版 Apache 2.0 开源建立信任，Pro 模块闭源。

### 1.1 个人开发者修正（2026-08-21）

上面「Team / 企业 / 云同步」对**有团队**时成立；**你一个人时按下列收缩**（细则见 [个人开发者商业化 FAQ](BoltShell_个人开发者商业化FAQ.md)）：

| 原方案 | 个人版调整 |
|--------|------------|
| Team 订阅、企业 SLA、云 Sync 当主业 | **先不做或偶接大单**；运维与客服是负债 |
| Pro 主卖「去广告 + 限连接解锁」 | **Pro 不去赞助**；卖真功能；忌纯「卖解锁」 |
| ¥1/月订阅 | **不要**；改低价买断（如支持者 ¥9.9 + Pro ¥88） |
| 推广堆很多卖点 | **主打已完成能力**：跨服务器直传文件 + 终端/SFTP/监控一体 |
| FinalShell 一键导入 | **尚未实现**（现有导入只导自己的 JSON）；做完再当宣传点 |

产品亮点、竞品表、一人维护功能优先级：见 [产品亮点与竞品对比](BoltShell_产品亮点与竞品对比.md)。

**卖解锁 vs 卖服务（B 端）：**

| | 卖解锁 | 卖服务 / B 端 |
|--|--------|----------------|
| 含义 | 人为加锁，付钱解开 | 付真成本：Sync、定制、开票、审计、支持 |
| 例子 | 限 5 连接、去广告 | Snippets、竞品导入、偶发企业授权 |
| 个人优先 | ❌ 弱 | ✅ 支持者买断 + 真功能 Pro + CPS + 赞助 |

## 二、收入模式设计

### 2.1 为什么不只靠广告

SSH 工具广告 CPM 很低，开发者工具类广告单价有限。粗算：

| 假设 | 数值 |
|------|------|
| 日活用户 | 1,000 |
| 每人每天看到广告 | 2 次 |
| 有效 CPM | ¥5–15 |
| **月广告收入（粗算）** | **¥300–900** |

对比：Pro ¥128 × 30 人/月 ≈ ¥3,840/月。广告需要 **10 倍以上流量** 才可能接近 Pro 收入。

**结论：广告适合当「免费版补贴」，Pro/Team 才是主力。**

这条粗算已被同行公开数据佐证：开源同类 **electerm** 的赞助档位是每月 **$35 / $135 / $400**，**Tabby** 的企业赞助档是 **$100/月**——独立 SSH 工具卖展示位，早期天花板就是每月几百到几千人民币。
同时，**桌面 SSH 客户端里没有一个头部产品在界面内投第三方广告**，Termius 与 Mobile SSH 反而把 `Ad-free` / `no ad banners on the terminal` 写成宣传语。
完整调研（含 FileZilla 捆绑翻车、npm 禁止终端广告、宝塔 / 向日葵 / ToDesk 对照）见 [竞品变现与广告风险调研](BoltShell_竞品变现与广告风险调研.md)。

### 2.1.1 更现实的第二收入：云厂商 CPS

| 平台 | 返佣 | 关键限制 |
|------|------|----------|
| 阿里云云大使 | 最高 **35%**（云资源类 25%） | 关联期 90 天（买大模型/Agent 可延至 365 天）；返利单 30 天后提现 |
| 腾讯云推广大使 | 新客首购 **20%–35%** | 仅个人实名；单笔上限 ¥5000；**只算首购**，续费/升级不返 |

```text
一台轻量应用服务器年付 ≈ ¥300，按 25% 返佣 ≈ ¥75/单
→ 成交 20 单 ≈ ¥1500，已超过 sidebar_1 一个月刊例上限
```

用户观感差异同样重要：**「推荐一台便宜的服务器」是功能，「一条 banner」是广告。**
但 CPS 波动大、有账期（阿里云 30 天、腾讯云次月结），**不能当固定收入排现金流**。

### 2.2 推荐三层结构

```
免费版（获客）  →  Pro 个人版（主力收入）  →  Team/Enterprise（高客单价）
     ↓                    ↓                           ↓
  个人开发者            重度用户/小工作室              公司采购
```

### 2.3 定价参考（国内市场）

| 版本 | 价格 | 目标用户 |
|------|------|----------|
| **Free** | ¥0 | 个人，≤5 台服务器 |
| **Pro** | ¥98–198 永久，或 ¥68/年 | 个人重度用户 |
| **Team** | ¥49/人/年（5 人起） | 小团队 |
| **Enterprise** | 面议，¥999+/年 | 审计、权限、私有化 |

**首发建议：** Pro **¥128 永久授权**（早鸟可 ¥88，限前 500 名）。

### 2.4 为什么 Pro 用买断而非纯订阅

- 国内开发者对 **一次性买断** 接受度更高（FinalShell、Navicat 等先例）
- 纯订阅需要持续云服务成本，早期负担重
- 可采用 **「买断 + 大版本升级费」** 兼顾现金流与续费

## 三、功能切分（Free / 支持者 / Pro）

> **权威清单以 [产品亮点与竞品对比 §五～§七](BoltShell_产品亮点与竞品对比.md) 为准**（含宣传口径、P0/P1、Pro 表）。下文为摘要。

原则：**Free 完成日常运维（含跨机传）；Pro 卖真功能；不去赞助；一人暂缓 Team/云 Sync。**

### 3.1 免费版

- SSH 终端 + SFTP + 监控 + **跨服务器直传**（灯塔，不阉割）
- 多 Tab、分组、自有 JSON 导入导出
- **不限会话数**（不推荐「限 5 连接」当卖点）
- 赞助位可见（可关）
- **待补进 Free：** 密钥/agent、SQLite 密码加密、HostKey、FinalShell 导入

### 3.2 支持者（¥9.9 买断）

- 徽章 + 官网致谢；可不解锁功能

### 3.3 Pro 版（¥88 买断，卖真代码）

| 功能 | 说明 |
|------|------|
| Snippets / 命令片段 | **推荐** |
| 会话日志录制 | **推荐** |
| 分屏 | 多 Tab 已在 Free |
| 端口转发 / 隧道 | 进阶 |
| `bolt` CLI 增强 / 批量多机 | 可后置进 Pro |
| ~~去除赞助~~ | **已否决** |
| ~~无限连接解锁~~ | **不推荐** |

至少 2～3 个真功能落地再上架 Pro。

### 3.4 Team / 企业（一人偶接）

云同步、审计、SSO、开票定制——有明确付费单再做；不预建。

### 3.5 暂不收费、用于拉用户

- 跨机直传、基础 SFTP、监控、连接稳定性
- 开源 Community（若走 Open Core）

## 四、广告 / 赞助位策略

### 4.1 模式：赞助位全员可见 + Pro 卖真功能（已定）

```
免费版 / 支持者 / Pro  →  赞助位均可看见（非操作区；可关闭单条）
Pro 版                 →  不「去赞助」；卖 Snippets / 录制 / 导入等真功能
```

赞助的作用：

1. 补贴开发 + 谈 CPT / CPS  
2. **不是** Pro 转化钩子里的「付钱去广告」（该钩子已否决）

详见 [产品亮点与竞品对比 §二](BoltShell_产品亮点与竞品对比.md) · [FAQ §2.3](BoltShell_个人开发者商业化FAQ.md)。
### 4.2 UI 位置评估

| 位置 | 评价 | 说明 |
|------|------|------|
| **左侧系统信息下方**（连接后，约 2 个小块） | ✅ 相对合适 | 空白区，不挡终端 / 文件操作；适合 60–80px 小 Banner |
| **快速连接页底部**（未连接时大块） | ✅ 相对合适 | 连接成功后自动隐藏；适合 100–120px 赞助卡片 |
| 终端区域内 | ❌ 禁止 | 打断运维 |
| 文件列表内 | ❌ 禁止 | 影响操作 |
| 弹窗 / 开屏 | ❌ 禁止 | 差评重灾区 |

**注意：**

- 连接数增多后，快速连接页空白变少，需预留布局
- 左侧栏未来可能加功能，广告位会变挤
- 运维用户对开发工具广告敏感，需克制

**已落地形态确认（见截图与调研 §8.1）：** 侧栏两条为**静态文字卡、固定吸底、无图片无动画**，位置本身无风险。
真正要守的是**行为约束**：

| ❌ 禁止行为 | 原因 |
|------------|------|
| 多素材轮播 / 定时切换 | 侧栏在会话中常驻可见，任何定时变化都在余光里抢注意力 |
| 远程图片懒加载改变卡片高度 | 加载完成时侧栏重排，视觉上就是「闪一下」；素材含图必须固定宽高占位，加载失败降级纯文字 |
| 与监控数据同流重排 | 进程列表定时刷新会带着赞助卡上下移动；赞助卡须 sticky/flex 吸底，不参与监控区重排 |
| 入场动画 | 挂载即最终态 |
| 第三方图片 banner | 文字卡与图片 banner 观感差一个量级，这是「自营鸣谢」变「广告位」的分界线；对外售出的 `sidebar_1` 也只接文字 + 角标 |

### 4.3 广告内容原则

| ✅ 可以 | ❌ 不要 |
|--------|--------|
| 自营推广（Pro 升级、新功能） | 百度 / 穿山甲等通用广告 SDK |
| 精选赞助（云厂商、域名、SSL、VPS） | 弹窗、开屏、终端内 |
| 开发者相关（CDN、监控、DevOps） | 游戏、贷款、菠菜 |
| 静态图文，可折叠 | 自动播放视频 |

**更推荐「赞助位」而非「广告位」：**

> 本工具由 XXX 云赞助 · [了解 Pro 去广告版]

- 按月卖 1～2 个赞助位（刊例约 **¥500～2000/月**，分位细则见 [赞助位报价与市场参考](BoltShell_赞助位报价与市场参考.md)），比纯 CPM 稳定
- 界面更专业，不像广告软件
- **不接通用广告 SDK**（SDK = 广告联盟开发工具包，如穿山甲），避免用户担心上报 IP、连接习惯等（SSH 工具信任成本高）
- 合作方式：**CPT**（Cost Per Time，按时间包断）包月 / 半月；改 `sponsors.json` 上下线

**位数量（与截图一致）：** 快速连接页 **1** 条；侧栏 **2** 条（仅 `sidebar_1` 对外卖）。快速连接底 **不要** 做成 2～3 条。

### 4.4 转化设计

- 赞助位旁可放：`支持开发 · 购买支持者 / Pro →`（**不要**写「升级去广告」）
- 设置页：`赞助 BoltShell 开发`
- 用户可关闭单条赞助（建议永久或长期，避免勒索感）
- **Pro 用户：赞助位默认仍显示**（与 §4.1 一致；若代码仍隐藏需改）

## 五、开源策略

### 5.1 是否应该开源？

**应该开源一部分，不建议 100% 全开源。**

| 策略 | 适合 BoltShell？ | 说明 |
|------|------------------|------|
| 完全闭源 | ❌ | 难获客；WindTerm、Tabby 已占「免费开源」心智 |
| 完全开源 (MIT) | ⚠️ 风险大 | 易被 fork 去广告、卖 Pro；难收费 |
| **Open Core** | ✅ **推荐** | 开源获客 + 信任，Pro/Team 闭源赚钱 |
| 先闭源后开源 | ⚠️ 可过渡 | v1.0 前快速迭代；GitHub 应尽早占位 |

### 5.2 竞品参考

| 产品 | 开源策略 | 怎么赚钱 |
|------|----------|----------|
| WindTerm | 完全开源 | 基本不收费 |
| Tabby | 开源 + 插件 | 赞助 / 企业支持（Corporate Sponsor **$100/月**，logo 进 README） |
| electerm | 完全开源 | GitHub Sponsors **$35 / $135 / $400 每月** logo 位；**客户端干净，云厂商 CPS 位全放官网** |
| FinalShell | 闭源 | 免费 + Pro；只推自家加速与高级版，**无第三方展示广告** |
| Termius | 闭源 | 订阅 + 云同步；免费版明确宣传 **`Ad-free`** |
| MobaXterm | 闭源 | 免费限功能 + Pro；仅终端底部 `UNREGISTERED VERSION` 角标 |

electerm 的做法值得直接抄：**客户端内保持干净，把阿里云 / 腾讯云优惠位放到官网赞助页**——既拿钱又不脏客户端。详见 [竞品变现与广告风险调研 §六](BoltShell_竞品变现与广告风险调研.md)。

BoltShell 定位：**个人开发、对标 FinalShell、Pro + 赞助** → 更接近 **Tabby + FinalShell 混合（Open Core）**。

### 5.3 Open Core 分层

```
┌─────────────────────────────────────────────┐
│  开源 Community（GitHub 公开）               │
│  · SSH 终端 + SFTP + 基础监控                │
│  · 连接管理（≤5 个）                         │
│  · 本地配置 · 赞助位（可选）                  │
│  License: Apache 2.0                         │
├─────────────────────────────────────────────┤
│  闭源 Pro（官网下载 / 付费解锁）              │
│  · 无限连接 · 去广告 · Snippets · 会话录制    │
│  · License 校验模块（不开源）                 │
├─────────────────────────────────────────────┤
│  闭源 Team（订阅）                            │
│  · 云同步 · 团队权限 · 审计日志               │
└─────────────────────────────────────────────┘
```

### 5.4 建议开源 vs 闭源

**✅ 开源（`github.com/boltshell-app/boltshell`）**

- Wails GUI 主体
- SSH / SFTP / 终端 / 基础监控
- 连接管理 CRUD
- `bolt` CLI 基础命令
- 文档、Logo、安装脚本

**🔒 闭源（私有仓库或编译进 Pro 二进制）**

- License 激活与校验
- 云同步后端（Team）
- 赞助位配置下发（可选）
- Pro 独有功能模块（Feature Flag / 插件隔离）

### 5.5 许可证

| 许可证 | 商业友好 | 专利保护 | 建议 |
|--------|----------|----------|------|
| MIT | ✅ | ❌ | 纯捐赠工具 |
| **Apache 2.0** | ✅ | ✅ | **Community 主仓库（当前 LICENSE 已是）** |
| GPL | ⚠️ | ✅ | 强制衍生开源，不适合 Pro 闭源 |
| BSL / SSPL / ELv2 | ✅ | — | **不是 OSI 开源**，只能叫「源码公开」；ELv2 是唯一在条款层面禁止「去广告 / 破解 Pro」的选项 |

**关键认知（详见 [开源许可证详解与选型](BoltShell_开源许可证详解与选型.md)）：**

| 我们担心的行为 | Apache-2.0 能防吗 |
|----------------|-------------------|
| 删掉赞助位重新编译 | ❌ 防不住 |
| 改 `IsPro()` 破解 Pro | ❌ 防不住 |
| 打包分发甚至收费卖 | ❌ 防不住 |
| **继续叫「BoltShell」** | ✅ **§6 明确不授予商标权** |

也就是说：**开源许可证在商业保护上基本无能，唯一有效的是「名字」。** 真正能防 fork 去广告的只有三条——不开源那部分代码、用 source-available 许可（ELv2/BSL）、商标。

**README 需写清：**

- Community 版：Apache 2.0
- `BoltShell` 名称与 Logo 为商标，Fork 需改名
- Pro / Team 为商业授权，不在开源范围内

### 5.6 全开源的主要风险

1. Fork 去广告版打包分发
2. Pro 功能被逆向（Go/Wails 仍可被分析）
3. 竞品抄 UI
4. 一旦承诺「永久全 MIT」，再改闭源会被骂「背叛社区」

**第一版就不要承诺「永久全开源」。** 规划文档 README 模板中的 MIT 应改为 Open Core 说明。

### 5.7 开源的好处

- GitHub Star、知乎 / V2EX 传播
- SSH 存密码，开源增加信任
- Issue / PR 补人力
- 长期 SEO 与个人品牌

## 六、产品形态与授权技术

### 6.1 架构

```
BoltShell Desktop (Wails)     ← 主产品、收费载体
bolt CLI                      ← 免费引流 + Pro 全功能
boltshell.com 官网            ← 下载、定价、文档
BoltShell Sync（可选）        ← Team 版云服务
```

### 6.2 License 方案（简单可落地）

1. **本地 License 文件**：邮箱 + 机器指纹 + RSA 签名
2. **离线激活**：适合国内用户，弱依赖服务器
3. **Team 版** 才需要账号体系 + 云同步 API
4. 代码预留 `license tier`：`free` / `pro` / `team`

```go
// 开源仓库中的接口
type LicenseChecker interface {
    IsPro() bool
    IsTeam() bool
}
// Community：永远 false
// Pro 二进制：链接闭源 license 库
```

## 七、获客与转化路径

### 7.0 推广主卖点（已具备，优先讲）

多数轻量 SSH 客户端 **没有**「跨服务器直接传文件」（常见是 A→本机→B）。BoltShell **已具备**跨机直传 + 终端/SFTP/监控一体——推广时**只打这一条主线**，避免十个卖点一起喊。

| 动作 | 说明 |

## 九、不建议做的事

1. ❌ 只有广告、没有 Pro —— 天花板低，口碑差
2. ❌ 连接中弹广告 —— 运维场景大忌
3. ❌ 免费版广告很多、Pro 功能很少 —— 像「勒索式免费」
4. ❌ 接第三方广告 SDK 不写隐私说明 —— 安全工具大忌
5. ❌ README 写 MIT，实际卖 Pro —— 法律与用户预期模糊
6. ❌ 先全开源 Star 够了再闭源 —— 信任崩塌
7. ❌ 等「功能完美」再收费 —— Pro 有 3~5 个杀手功能即可上架
8. ❌ 免费版限制「只能用 7 天」—— 用户会换 WindTerm
9. ❌ **安装包捆绑第三方 offer** —— FileZilla / WinSCP 教训：不只掉口碑，**杀软报毒会直接掐死下载转化**（Defender 会标 `App:FileZilla_BundleInstaller` 这类 PUA）
10. ❌ **`bolt` CLI 输出里出现赞助 / 广告信息** —— 含 `--version`、首次运行与更新提示。2019 年 `standard` 在 `npm install` 打赞助横幅，社区当天造出 `npm-adblock`，npm 官方随即改政策全面禁止终端广告
11. ❌ **赞助素材用图片 banner 或自动播放内容** —— 只接文字 + 角标；素材限运维相关（云、域名、SSL、CDN、监控、DevOps）
12. ❌ **相信「非侵入式横幅」这个说法** —— Bandizip 7.0 就是这么解释的，结果老用户集体停留在无广告的 6.29 或转投 7-Zip。用户视角只有「有广告 / 没广告」两档
