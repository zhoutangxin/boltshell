## 一、两个页面各几个广告位？

客户端只有两种界面态，位 **互斥**（不会同时出现全部 3 条）。

| 页面 | 建议数量 | slotId | 是否对外卖 |
|------|----------|--------|------------|
| **快速连接**（未连接） | **1 个** | `quick_connect_bottom` | 可卖（品牌位，价可更高） |
| **系统信息侧栏**（已连接） | **2 个** | `sidebar_1` / `sidebar_2` | 只卖 `sidebar_1`；`sidebar_2` 默认自营 Pro |

### 1.1 快速连接页为什么坚持 1 条（不要 2～3 条）

底部 **居中窄条（约 52px）** 已平衡「有存在感」和「不抢操作」。

| 若做成 2～3 条 | 问题 |
|----------------|------|
| 像广告软件 | 运维用户反感强，差评 / 卸载风险升 |
| 挤连接列表 | 列表变长后，多条底栏会吃掉可视区 |
| 伤 Pro 叙事 | 广告越多，「去广告」越像勒索 |
| 与规划冲突 | 中间空白留给列表增长，**不要**在中间再插广告 |

**若一定要多卖：** 优先加价卖这一条 + 卖侧栏 `sidebar_1`；不要在快速连接底堆卡片。设置页文字链可作 v2，也不要在本页堆到 3 条。

### 1.2 侧栏为什么是 2 条

- 上条 `sidebar_1`：外部精选赞助（主售）  
- 下条 `sidebar_2`：升级 Pro、永久去广告（转化钩子，**默认不卖**）

## 二、CPT / SDK 是什么？（对外话术必懂）

### 2.1 CPT = Cost Per Time（按时间付费）

甲方按 **占用广告位的时长** 付钱（包天 / 包周 / **包半月 / 包月**），**不按**实际曝光次数、不按点击次数结算。

| 缩写 | 全称 | 怎么收钱 |
|------|------|----------|
| **CPT** | Cost Per Time | 按时间包断某个位 |
| CPM | Cost Per Mille | 每 1000 次曝光计价 |
| CPC | Cost Per Click | 每次点击计价 |

**BoltShell 合作方式一句话：**

> CPT 包月 / 半月；改服务器 `sponsors.json` 即可上下线；**不接**第三方广告 SDK。

公开释义参考：[MBA 智库 · CPT广告](https://wiki.mbalib.com/wiki/CPT%E5%B9%BF%E5%91%8A)、[百度百科 · CPT（广告术语）](https://baike.baidu.com/item/CPT/12978085)。

### 2.2 「不接第三方广告 SDK」含义

**SDK = Software Development Kit（软件开发工具包）**。  
这里特指 **穿山甲 / 优量汇 / 百度联盟** 等广告联盟 SDK：装进客户端后由联盟自动拉广告、展示、计费。

| | 接第三方广告 SDK | BoltShell 做法 |
|--|------------------|----------------|
| 广告来源 | 联盟自动填充 | 自建 `sponsors.json` 精选赞助 |
| 数据风险 | SDK 可能采集设备等信息 | 不把 SSH 场景交给广告联盟 |
| 界面 | 易杂、易多 | 固定 1～2 条，可控 |
| 信任 | 运维工具用户极敏感 | 「不接 SDK」更好讲故事 |

## 三、建议刊例（BoltShell 自己卖多少钱）

> 早期人少取**下限**；有免费 MAU / 分位曝光后再上调。  
> 半月价约为月价的 **60%～70%**（不是对半砍：换素材与对接成本接近整月）。

| 位 | 月价（建议） | 半月价（建议） | 备注 |
|----|--------------|----------------|------|
| `sidebar_1`（主售） | **¥800～1500** | **¥500～900** | 优先主推 |
| `quick_connect_bottom` | **¥1200～2000** | **¥700～1200** | 连机前必经，品牌感更强 |
| `sidebar_2` | 不对外卖 | — | 自营 Pro |
| 两月位打包（侧栏+快速连接） | **¥1800～2800 / 月** | 另议 | 大客户可谈 |

与既有商业化草案（约 **¥500～2000/月** 卖 1～2 个位）一致，本章把位拆开写清。

### 3.1 详细报价示例 A：侧栏主位 · 半月试投

| 项目 | 内容 |
|------|------|
| 位置 | 已连接 · 系统信息侧栏 · `sidebar_1`（约 240×64） |
| 周期 | 例如 2026-09-01 ～ 2026-09-15（半月） |
| 费用 | **¥600**（含 1 次素材更换） |
| 素材 | 角标≤4 字 + 标题≤16 字 + 描述≤20 字 + 跳转 URL |
| 示例文案 | `[云]` **某某云 · 新用户上云礼包** / `SSH 场景专属优惠 →` |
| 我方 | 上线 / 到期下线；有埋点后可提供曝光与点击汇总 |
| 甲方自核 | URL 加 `utm_source=boltshell&utm_medium=sidebar_1` |
| 重要声明 | 早期 **不保量**（CPT 包断，非保底曝光合同） |
| 续约 | 可转月包 **¥1000/月**，同素材优先 |

### 3.2 详细报价示例 B：快速连接底 · 整月品牌位

| 项目 | 内容 |
|------|------|
| 位置 | 未连接 · 快速连接页底部居中窄条（约 560×52） |
| 周期 | 整月 |
| 费用 | **¥1500** |
| 卖点话术 | 启动后、连机前必经；品牌曝光强于侧栏小卡 |
| 声明 | 仍为 CPT；不接广告 SDK；Pro 用户不展示 |

### 3.3 用「等效 CPM」自检贵不贵（内部算，不必写进合同）

```text
等效 CPM（元）≈ 月费 ÷ (月曝光次数 / 1000)
例：sidebar_1 月费 ¥1000，月曝光 5 万次 → 等效 CPM ≈ ¥20
```

- 若等效 CPM 远高于下文「公开市场开发者广告 CPM」上限，甲方会觉得贵 → 降价或等量起来再卖。  
- 若远低于市场，说明包月价还有上调空间。  
- **早期无曝光实数时：不要对外报等效 CPM**，只报 CPT 刊例 + 人群。

| **FinalShell** | 免费 + 专业版常见宣传约 **¥128 买断**；有广告/会员叙事；**未见**官方「赞助位刊例价」公开页 | 可对标商业模式，**不能**抄它的未公开广告价 |
| 商业化文档粗算 | 若免费用户量级有限，纯广告月收可能只有 **数百元量级**，故 **不能只靠广告** | 见 [商业化与开源策略](BoltShell_商业化与开源策略.md) |

### 4.4 对 BoltShell 定价的含义

1. **海外开发者广告按 CPM 卖时**，千次往往等价 **几十元人民币**；要卖出 ¥1000+/月，需要 **足够曝光** 或改讲「精准运维人群 + CPT 包断」。  
2. **国内中小垂直站 CPT 包月** 常见 **千元～两千元/月** 一档，与我们建议的 `sidebar_1` **¥800～1500** 同量级——适合早期。  
3. **客户端内精选赞助** 比网页 Banner 更「场景内」，但量通常小于大站；早期用 **CPT + 不保量 + UTM 自核**。  
4. **涨价时机**：正式包 **已带埋点** 并跑过一段时间有实数后，再上调 CPT——**禁止**「无埋点先发版、指望用户升级后再统计」。详见统计设计 §1.1。  
5. CTR 预期：工具内原生条可参考行业 native / in-tool **约 1%～2% 量级**；达不到别慌，甲方更看人群是否精准。

## 五、合作话术（可直接发给甲方）

> BoltShell 是一体化 SSH 客户端。免费版在非操作区展示精选赞助位（快速连接底 1 条 / 已连接侧栏对外 1 条），**不接入**穿山甲等第三方广告 SDK。  
> 合作按 **CPT**：包半月或包月买断指定位，我们改服务器配置上下线。  
> 人群为国内运维与后端；Pro 用户去广告，可售触达以免费用户为准。  
> 早期提供位图与刊例；有匿名统计后可提供分位曝光/点击。链接请加 UTM 便于贵司自核。  
> **不承诺保底曝光**（除非另行书面约定且具备稳定埋点数据）。
