## 三、产品亮点（按「能不能当标题」排序）

### 3.1 主亮点（已具备，宣传主线只打这两条）

| # | 亮点 | 用户一句话 | 为何多数竞品弱 |
|---|------|------------|----------------|
| 1 | **跨服务器直传文件** | 不用先下到电脑，A 机文件直接到 B 机 | 见 §3.4 |
| 2 | **终端 + SFTP + 监控一体** | 一个窗口连上就能敲命令、传文件、看 CPU/内存 | Tabby/WindTerm 偏终端；纯 SFTP 无监控同屏 |

### 3.2 辅助亮点（有，放「体验」里，不当唯一标题）

| 亮点 | 说明 |
|------|------|
| 多 Tab / 分组管理 | 标配 |
| 远端文件在线编辑 | 加分 |
| 终端 GB18030 兜底 | 国内加分 |
| **编辑连接时密码可见切换**（🙈） | 体验加分，少输错；**不是安全卖点**；与「落盘加密」是两回事 |
| 赞助位克制 | 不进终端/文件区/弹窗 |

### 3.3 勿当亮点宣传（尚未达标）

| 文档/文案曾写 | 实际 |
|---------------|------|
| 网络实时图表 | 仅有 CPU/内存/Swap/磁盘/Top 进程 |
| FinalShell / Xshell 一键导入 | 仅有**自有 JSON** 导入导出 |
| 密钥登录 / ssh-agent | 以密码登录为主，**必须补（P0）** |
| 批量多机命令 | 「命令」Tab 多为壳 |
| 密码本地加密存储 | 仍偏明文 SQLite，**必须补（P0）** |

### 3.4 为什么跨机传送「好做」市面却少做？

不是做不到，是**产品边界与成本**：

| 原因 | 说明 |
|------|------|
| 历史模型 | 传统是「本机 ↔ 一台远端」（WinSCP）；A→B 要同时管两台 |
| 定位不同 | Termius 重心多端同步；PuTTY 极简终端；Tabby 偏现代终端 |
| 工程不止「再开 SFTP」 | 目标机未开 Tab、浏览、进度/失败、大文件、双端认证；你们已有连接池 |
| 需求被低估 | 很多人习惯 scp 中转或先下再传 |
| 支持成本 | 「传丢了」比本机上传更难缠，小团队常故意不做 |

→ **你做成了，就反复当主卖点**；不是因为别人做不到。

### 3.5 「不补加密/密钥，读者会觉得又一个 SSH+SFTP」是什么意思？

不是说你「只有 SSH+SFTP 就没价值」。  
是指读者扫功能清单时的**默认归类**：能连 + 能传文件的工具一筐。若看不出「凭据怎么存、能不能密钥登、跨机传/监控」等差异，会懒得细看。  
补密钥/加密 = 跨过「敢不敢当主力」；亮点仍靠跨机传等来讲。

### 3.6 密码存 SQLite 再加密——用户接受吗？

**接受，且常见。** 用户不在意是不是 SQLite，在意：

> 别人拷走数据库文件，能不能直接读出密码？

| 方案 | 接受度 |
|------|--------|
| SQLite 字段 AES-GCM 密文 + 主密钥在 OS Keychain/DPAPI | ✅ 推荐 |
| SQLCipher 整库加密 | ✅ |
| 明文 SQLite | ❌ |

继续用 SQLite 完全没问题。

### 4.1 Termius 技术栈（性能对比用）

| 项 | Termius Desktop |
|----|-----------------|
| 壳 | **Electron** |
| UI | **React + TypeScript** |
| 其它 | Node.js、xterm.js、原生 **C++** 模块（SSH/PTY 等） |

→ 与 Termius 比内存 = **同类 GUI 对比**，比和系统 `ssh` 比更有说服力。  
你测到同量级 → Go+Wails **不虚**；不必追「Rust 高性能」话术。

### 4.2 Go vs「Rust 高性能」营销

- SSH 客户端瓶颈多在网络、终端渲染、会话数，很少是 Go vs Rust 几个百分点。  
- 「Rust 高性能」多为相对 Java/Electron 臃肿的营销句。  
- 对外建议写：**后端 Go；Mac 上与 Termius 等同档 GUI 同场景内存同量级**——用实测，不跟风语言品牌。

### 4.3 FinalShell「有没有广告」——勿乱写

| 可能有的 | 说明 |
|----------|------|
| 升级高级版、云同步、加速等**自家提示** | 不等于穿山甲式第三方广告 |
| 你本机若没看见弹窗硬广 | **对比文不要写「FinalShell 广告多」** |

宣传只说自己：**无弹窗、无安装捆绑、赞助克制可关**——少贬竞品未核实的点。

### 4.4 XPipe / sshxterm（掘金常见安利）

| | [XPipe](https://github.com/xpipe-io/xpipe) | [sshxterm](https://www.sshxterm.com/) | BoltShell |
|--|------|----------|-----------|
| 开源？ | **是，Open Core**（Apache 2.0 核心 + 专业组件闭源） | 公开资料偏**免费闭源/官网安装包**；勿与 GitHub `sshx`（另一项目）混淆 | 待定 Open Core |
| 主战场 | Docker/K8s/多环境连接中心 | 加密 + 免费无广告叙事 | **跨机传 + 监控同屏** |
| SFTP | 有 | 有（文案含 SFTP + lrzsz） | 同屏图形面板 |

「核心永久免费、企业高阶收费」= 个人免费用满 + B 端另收——**模式可参考**；勿照抄「无广告、无阉割」满话（你有赞助鸣谢；以后若收 Pro 功能会被抠字眼）。

适合你的改写：

> 个人日常：核心能力免费（终端/SFTP/监控/跨机传），不限会话数；无弹窗、无捆绑；侧栏赞助可关。  
> 支持者/Pro：致谢或真功能；企业面议。

## 五、产品还要支持哪些（一人维护优先级）

原则：**先信任与迁移（P0），再 Pro 真功能（P1），云/企业后置（P2）。**  
灯塔功能（跨机传、监控）**留在 Free，不阉割卖钱。**

### P0 — 下一阶段只做这些

| 功能 | 为什么 | 归属 |
|------|--------|------|
| **SSH 密钥登录** + ssh-agent | 严肃运维标配；**要做** | Free |
| **SQLite 密码加密** + OS Keychain 主密钥 | 拷库读不出明文 | Free |
| **HostKey / known_hosts** | 勿长期 Ignore | Free |
| **FinalShell 一键导入** | 迁移文章前提 | Free（获客） |
| 赞助：Pro 仍可见；可 dismiss | 商业决策一致 | — |
| 官网抓包示例 + 隐私 | 埋点信任 | — |

### P1 — 有余力 / 可作 Pro

| 功能 | 建议归属 |
|------|----------|
| Xshell 导入 | Free 或迁移工具 |
| **Snippets / 命令片段** | **Pro** |
| **会话日志录制** | **Pro** |
| 分屏 | **Pro**（多 Tab 已在 Free） |
| 端口转发 / 隧道 | **Pro** 或后期 |
| 「查看我上报的数据」 | Free |
| 批量多机命令 | 可慢；做成后可 Pro |
| 监控补网络图 | 可选，对齐旧文案 |
| 密码管理增强（生成/保险库） | 后期；与「密码可见」无关 |

### P2 — 一人暂缓

云 Sync、Team 审计/SSO、完整 `bolt` CLI 生态、主题市场、插件系统。

### 明确不做

- 限 5 连接 / 去赞助当 Pro 主卖点  
- 安装捆绑、弹窗、终端区广告  
- 阉割跨机传/监控逼付费

## 六、产品如何宣传

### 6.1 一句话 / 30 秒

> BoltShell：一体化 SSH 运维客户端——终端、SFTP、监控同屏。  
> **和其他工具最大的不同：服务器之间可以直接传文件，不用先下载到自己电脑。**  
> Go + Wails；Mac 上与 Termius 等同档客户端内存同量级。

### 6.2 渠道与顺序（零预算）

| 优先级 | 动作 |
|--------|------|
| 1 | 知乎/掘金/V2EX/博客园：**跨机传文件** + FinalShell 替代（导入做完再写迁移文） |
| 2 | README / 官网：GIF（跨机传、监控同屏）；勿超前承诺 |
| 3 | 小众软件、异次元、蓝点、少数派投稿 |
| 4 | 持续发版日志 |
| 5 | Show HN / 英文材料（有余力） |

学安利文结构：**痛点 → 亮点 → 对比表 → 下载**；表里只写已实现能力。

### 6.3 禁止宣传口径

| ❌ 不要写 | 原因 |
|----------|------|
| Rust 高性能碾压 | 你是 Go；用实测说话 |
| FinalShell 广告多 | 未核实；你可能根本没看见 |
| 已支持密钥/竞品导入/已加密 | 未做完前禁止 |
| 无广告（若有赞助位） | 改写「无弹窗、赞助可关」 |
| 无阉割（若以后有 Pro 功能） | 改写「核心运维免费」 |

### 6.4 对比话术（诚实）

**vs FinalShell：** 一体化接近；我们强调跨机直传；密钥/导入还在补。  
**vs Termius：** 他强在多端云同步（Electron）；我们强在同屏监控+跨机传，无强制云账号。  
**vs Tabby/WindTerm：** 他们偏终端；我们偏运维工作台。  
**vs sshxterm：** 都有 SSH+SFTP；我们主打跨机直传+监控同屏；密钥/加密要对齐后再硬刚「安全」叙事。

## 七、Free / 支持者 / Pro 功能怎么切

### 7.1 Free（拉用户，必须够用）

- SSH（密码；**补完后含密钥**）、多 Tab  
- SFTP、远端编辑、本机↔远端传输  
- **跨服务器直传**、侧栏监控  
- 分组、自有 JSON 导入导出、**FinalShell 导入（做完后）**  
- 密码可见切换、应用内更新  
- 赞助位可见（可关）  
- **不限会话数**（不推荐用连接数卡人）

### 7.2 支持者 ¥9.9

- 不解锁核心功能也可  
- 徽章 + 官网致谢  

### 7.3 Pro 额外功能（买断，卖真代码）

| Pro 功能 | 状态建议 | 付费理由 |
|----------|----------|----------|
| Snippets / 命令片段 | 待做 → Pro | 每天省时间 |
| 会话日志录制 | 待做 → Pro | 排错留痕 |
| 分屏（多会话同视） | 待做 → Pro | 多 Tab 已 Free |
| 端口转发 / 隧道 | 待做 → Pro | 进阶组网 |
| `bolt` CLI 增强 | 待做 → 可 Pro | CLI 用户愿付 |
| 批量多机命令 | 待做 → 可 Pro | 集群效率 |
| ~~去赞助~~ | **否决** | — |
| ~~限连接解锁~~ | **不推荐** | 卖解锁 |

**上架门槛：** 至少 2～3 个上表真功能落地再卖 Pro；空壳 Pro 不要发。

### 7.4 企业（偶接，不预建）

开票、定制、审计、国产化适配——有单再做。
