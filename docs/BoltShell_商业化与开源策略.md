## 一、总体结论（先看这个）

| 维度 | 建议 |
|------|------|
| **主收入模式** | Freemium + Pro 买断 + Team 订阅（不要只靠广告） |
| **广告** | 可以做，放在非操作区；作为免费版补贴 + Pro 转化钩子 |
| **开源** | Open Core：Community 开源获客，Pro/Team 闭源赚钱 |
| **许可证** | Community 用 Apache 2.0（仓库已有），商标 BoltShell 单独保护 |

**一句话策略：**

> 用「免费、轻量、比 FinalShell 干净」抢个人用户；用「无限连接 + 效率工具 + 去广告」卖 Pro；用「团队同步 + 审计」卖公司；Community 版 Apache 2.0 开源建立信任，Pro 模块闭源。

## 二、收入模式设计

### 2.1 为什么不只靠广告

SSH 工具广告 CPM 很低，开发者工具类广告单价有限。粗算：

| 假设 | 数值 |
|------|------|
| 日活用户 | 1,000 |
| 每人每天看到广告 | 2 次 |
| 有效 CPM | ¥5–15 |
| **月广告收入（粗算）** | **¥300–900** |

对比：Pro ¥128 × 30 人/月 ≈ ¥3,840/月。广告需要 **10 倍以上流量** 才可能接近 Pro 收入。

**结论：广告适合当「免费版补贴」，Pro/Team 才是主力。**

### 2.2 推荐三层结构

```
免费版（获客）  →  Pro 个人版（主力收入）  →  Team/Enterprise（高客单价）
     ↓                    ↓                           ↓
  个人开发者            重度用户/小工作室              公司采购
```

### 2.3 定价参考（国内市场）

| 版本 | 价格 | 目标用户 |
|------|------|----------|
| **Free** | ¥0 | 个人，≤5 台服务器 |
| **Pro** | ¥98–198 永久，或 ¥68/年 | 个人重度用户 |
| **Team** | ¥49/人/年（5 人起） | 小团队 |
| **Enterprise** | 面议，¥999+/年 | 审计、权限、私有化 |

**首发建议：** Pro **¥128 永久授权**（早鸟可 ¥88，限前 500 名）。

### 2.4 为什么 Pro 用买断而非纯订阅

- 国内开发者对 **一次性买断** 接受度更高（FinalShell、Navicat 等先例）
- 纯订阅需要持续云服务成本，早期负担重
- 可采用 **「买断 + 大版本升级费」** 兼顾现金流与续费

## 三、功能切分（Free / Pro / Team）

原则：**免费版完成 80% 日常运维；付费版解决多机、协作、效率、安全。**

### 3.1 免费版（Personal / Community）

- SSH 终端 + SFTP 文件管理
- 保存 **≤5 个** 连接
- 基础监控（CPU / 内存 / 磁盘）
- 单机本地存储配置
- 跨服务器文件传送（可作为差异化保留）
- 底部 **赞助位**（见第四节）

### 3.2 Pro 版（个人买断）

| 功能 | 付费理由 |
|------|----------|
| **无限连接数** | 管理 20+ 台机器刚需 |
| **去除广告 / 赞助位** | 明确转化钩子 |
| **连接分组 + 标签** | 多项目运维 |
| **Snippets / 命令片段** | 高频命令一键执行 |
| **多 Tab / 分屏** | 效率提升 |
| **会话日志录制** | 排错、留痕 |
| **端口转发 / 隧道管理** | 进阶运维 |
| **主题 / 布局同步（本地）** | 个性化 |
| **导入 Xshell / FinalShell 配置** | 降低迁移成本 |
| **`bolt` CLI 全功能** | 命令行用户付费意愿较高 |

### 3.3 Team 版（订阅）

| 功能 | 付费理由 |
|------|----------|
| **加密云同步**（配置，不含密码明文） | Termius 核心付费点 |
| **团队共享连接库** | 运维交接、新人 onboarding |
| **权限角色**（只读 / 可连 / 可传文件） | 企业合规 |
| **操作审计日志** | 等保、内审 |
| **统一密钥托管**（可选对接 Vault） | 安全团队需求 |
| **SSO / LDAP** | 大企业采购门槛 |
| **永远无广告** | 企业版标配 |

### 3.4 暂不收费、用于拉用户

- 核心连接稳定性与速度（Slogan：闪电连接）
- 基础 SFTP、监控
- 开源 Community 版源码（建立信任）

## 四、广告 / 赞助位策略

### 4.1 模式：FinalShell 式「广告 + 去广告付费」

```
免费版  →  有赞助位（非操作区）
Pro 版  →  永久去广告 + 高级功能
```

广告的两个作用：

1. 给不愿付费的用户「看赞助免费用」的选择
2. 给愿意付费的用户明确理由：「¥128 买断，干净无广告」

### 4.2 UI 位置评估

| 位置 | 评价 | 说明 |
|------|------|------|
| **左侧系统信息下方**（连接后，约 2 个小块） | ✅ 相对合适 | 空白区，不挡终端 / 文件操作；适合 60–80px 小 Banner |
| **快速连接页底部**（未连接时大块） | ✅ 相对合适 | 连接成功后自动隐藏；适合 100–120px 赞助卡片 |
| 终端区域内 | ❌ 禁止 | 打断运维 |
| 文件列表内 | ❌ 禁止 | 影响操作 |
| 弹窗 / 开屏 | ❌ 禁止 | 差评重灾区 |

**注意：**

- 连接数增多后，快速连接页空白变少，需预留布局
- 左侧栏未来可能加功能，广告位会变挤
- 运维用户对开发工具广告敏感，需克制

### 4.3 广告内容原则

| ✅ 可以 | ❌ 不要 |
|--------|--------|
| 自营推广（Pro 升级、新功能） | 百度 / 穿山甲等通用广告 SDK |
| 精选赞助（云厂商、域名、SSL、VPS） | 弹窗、开屏、终端内 |
| 开发者相关（CDN、监控、DevOps） | 游戏、贷款、菠菜 |
| 静态图文，可折叠 | 自动播放视频 |

**更推荐「赞助位」而非「广告位」：**

> 本工具由 XXX 云赞助 · [了解 Pro 去广告版]

- 按月卖 1–2 个赞助位（¥500–2000/月），比 CPM 稳定
- 界面更专业，不像广告软件
- **不接通用广告 SDK**，避免用户担心上报 IP、连接习惯等（SSH 工具信任成本高）

### 4.4 转化设计

- 赞助位下方：`升级到 Pro，永久去除广告 →`
- 设置页：`赞助 BoltShell 开发，购买 Pro`
- 免费用户可「7 天内不再显示」（勿永久关闭，否则无人买 Pro）
- **Pro 用户：赞助位整块隐藏**

## 五、开源策略

### 5.1 是否应该开源？

**应该开源一部分，不建议 100% 全开源。**

| 策略 | 适合 BoltShell？ | 说明 |
|------|------------------|------|
| 完全闭源 | ❌ | 难获客；WindTerm、Tabby 已占「免费开源」心智 |
| 完全开源 (MIT) | ⚠️ 风险大 | 易被 fork 去广告、卖 Pro；难收费 |
| **Open Core** | ✅ **推荐** | 开源获客 + 信任，Pro/Team 闭源赚钱 |
| 先闭源后开源 | ⚠️ 可过渡 | v1.0 前快速迭代；GitHub 应尽早占位 |

### 5.2 竞品参考

| 产品 | 开源策略 | 怎么赚钱 |
|------|----------|----------|
| WindTerm | 完全开源 | 基本不收费 |
| Tabby | 开源 + 插件 | 赞助 / 企业支持 |
| FinalShell | 闭源 | 免费广告 + Pro |
| Termius | 闭源 | 订阅 + 云同步 |
| MobaXterm | 闭源 | 免费限功能 + Pro |

BoltShell 定位：**个人开发、对标 FinalShell、Pro + 赞助** → 更接近 **Tabby + FinalShell 混合（Open Core）**。

### 5.3 Open Core 分层

```
┌─────────────────────────────────────────────┐
│  开源 Community（GitHub 公开）               │
│  · SSH 终端 + SFTP + 基础监控                │
│  · 连接管理（≤5 个）                         │
│  · 本地配置 · 赞助位（可选）                  │
│  License: Apache 2.0                         │
├─────────────────────────────────────────────┤
│  闭源 Pro（官网下载 / 付费解锁）              │
│  · 无限连接 · 去广告 · Snippets · 会话录制    │
│  · License 校验模块（不开源）                 │
├─────────────────────────────────────────────┤
│  闭源 Team（订阅）                            │
│  · 云同步 · 团队权限 · 审计日志               │
└─────────────────────────────────────────────┘
```

### 5.4 建议开源 vs 闭源

**✅ 开源（`github.com/boltshell-app/boltshell`）**

- Wails GUI 主体
- SSH / SFTP / 终端 / 基础监控
- 连接管理 CRUD
- `bolt` CLI 基础命令
- 文档、Logo、安装脚本

**🔒 闭源（私有仓库或编译进 Pro 二进制）**

- License 激活与校验
- 云同步后端（Team）
- 赞助位配置下发（可选）
- Pro 独有功能模块（Feature Flag / 插件隔离）

### 5.5 许可证

| 许可证 | 商业友好 | 专利保护 | 建议 |
|--------|----------|----------|------|
| MIT | ✅ | ❌ | 纯捐赠工具 |
| **Apache 2.0** | ✅ | ✅ | **Community 主仓库（当前 LICENSE 已是）** |
| GPL | ⚠️ | ✅ | 强制衍生开源，不适合 Pro 闭源 |
| BSL / SSPL | ✅ | — | 防云厂商白嫖，早期过重 |

**README 需写清：**

- Community 版：Apache 2.0
- `BoltShell` 名称与 Logo 为商标，Fork 需改名
- Pro / Team 为商业授权，不在开源范围内

### 5.6 全开源的主要风险

1. Fork 去广告版打包分发
2. Pro 功能被逆向（Go/Wails 仍可被分析）
3. 竞品抄 UI
4. 一旦承诺「永久全 MIT」，再改闭源会被骂「背叛社区」

**第一版就不要承诺「永久全开源」。** 规划文档 README 模板中的 MIT 应改为 Open Core 说明。

### 5.7 开源的好处

- GitHub Star、知乎 / V2EX 传播
- SSH 存密码，开源增加信任
- Issue / PR 补人力
- 长期 SEO 与个人品牌

## 六、产品形态与授权技术

### 6.1 架构

```
BoltShell Desktop (Wails)     ← 主产品、收费载体
bolt CLI                      ← 免费引流 + Pro 全功能
boltshell.com 官网            ← 下载、定价、文档
BoltShell Sync（可选）        ← Team 版云服务
```

### 6.2 License 方案（简单可落地）

1. **本地 License 文件**：邮箱 + 机器指纹 + RSA 签名
2. **离线激活**：适合国内用户，弱依赖服务器
3. **Team 版** 才需要账号体系 + 云同步 API
4. 代码预留 `license tier`：`free` / `pro` / `team`

```go
// 开源仓库中的接口
type LicenseChecker interface {
    IsPro() bool
    IsTeam() bool
}
// Community：永远 false
// Pro 二进制：链接闭源 license 库
```

## 九、不建议做的事

1. ❌ 只有广告、没有 Pro —— 天花板低，口碑差
2. ❌ 连接中弹广告 —— 运维场景大忌
3. ❌ 免费版广告很多、Pro 功能很少 —— 像「勒索式免费」
4. ❌ 接第三方广告 SDK 不写隐私说明 —— 安全工具大忌
5. ❌ README 写 MIT，实际卖 Pro —— 法律与用户预期模糊
6. ❌ 先全开源 Star 够了再闭源 —— 信任崩塌
7. ❌ 等「功能完美」再收费 —— Pro 有 3~5 个杀手功能即可上架
8. ❌ 免费版限制「只能用 7 天」—— 用户会换 WindTerm
